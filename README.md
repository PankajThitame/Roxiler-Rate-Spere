# Run instructions (local)

Backend (NestJS + TypeORM)

1. From project root, install dependencies in `backend` (if not already):

```bash
cd backend
npm install
```

2. Seed DB (dev):

```bash
npm run seed
```

3. Build and run production node app (this workspace uses port 3001):

```bash
npm run build
# If port 3000 is occupied, set PORT before starting
#$env:PORT=3001 ; npm run start:prod
npx cross-env PORT=3001 npm run start:prod
```

Frontend (Vite + React)

1. From project root:

```bash
cd frontend
npm install
npm run dev
```

The frontend by default points to `http://localhost:3001` for the API. To override, set `VITE_API_URL` in your environment.

Smoke checks and tests

From `backend`:

```bash
# quick smoke
node scripts/smoke-checks.js

# e2e tests
npm run test:e2e
```# RateSphere - Store Rating Platform

A production-grade, enterprise-ready Full Stack Store Rating and Feedback Platform built with React 19, NestJS, Tailwind CSS, TypeORM, and MySQL 8.

---

## Technical Stack

*   **Frontend**: React 19, Vite, React Router, Axios, Tailwind CSS, React Hook Form, React Toastify, Lucide Icons.
*   **Backend**: NestJS, TypeScript, JWT Auth (passport-jwt), BCrypt Password Hashing, Class Validator, Helmet, Express Rate Limiting.
*   **Database & ORM**: MySQL 8, TypeORM.

---

## Environment Variables

### Backend Configurations (`/backend/.env`)

Create a `.env` file in the `/backend` directory:

```env
PORT=3000
DB_HOST=localhost
DB_PORT=3306
DB_USERNAME=root
DB_PASSWORD=root
DB_DATABASE=store_rating_platform
JWT_SECRET=super-secret-jwt-key-change-in-production-1234567890
JWT_EXPIRATION=24h
```

## Database Setup

1.  Start your local **MySQL 8** server.

## Installation & Running

### 1. Start the Backend API

Navigate to the `backend` folder, install dependencies, run the database seed script, and boot the server:

```bash
cd backend
npm install
npm run seed
npm run start:dev
```

*   **Backend Server**: `http://localhost:3000`
*   **Swagger API Docs**: `http://localhost:3000/api/docs`

### 2. Start the Frontend Application

Navigate to the `frontend` folder, install dependencies, and start the Vite dev server:

```bash
cd frontend
npm install
npm run dev
```

*   **Frontend Client**: `http://localhost:5173`

## Production Build & Deployment

### Build Backend
```bash
cd backend
npm run build
```
This outputs compiled TypeScript files to `/backend/dist`. Run it in production with: `npm run start:prod`.

### Build Frontend
```bash
cd frontend
npm run build
```
This builds static assets to `/frontend/dist`. Serve these static files from an Nginx or similar web server.
